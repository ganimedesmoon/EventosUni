# EventosUni

O **EventosUni** é um sistema desenvolvido com o objetivo de apresentar, de forma prática e objetiva, a aplicação dos **quatro principais paradigmas de programação** por meio de uma aplicação voltada ao gerenciamento de eventos acadêmicos.

O projeto foi desenvolvido como uma forma de relacionar conceitos teóricos de programação com uma aplicação funcional, permitindo observar diferentes abordagens de desenvolvimento dentro de um mesmo sistema.

## Objetivo

Demonstrar os **quatro paradigmas de programação** utilizando o sistema EventosUni como base prática:

* **Programação Imperativa**
* **Programação Orientada a Objetos**
* **Programação Funcional**
* **Programação Lógica**

A proposta é apresentar as características de cada paradigma e evidenciar como diferentes formas de pensar e estruturar um programa podem ser aplicadas ao desenvolvimento de um sistema.

## Sobre o Sistema

O EventosUni é um sistema voltado para a **organização e gerenciamento de eventos universitários**.

A aplicação serve como ambiente prático para demonstrar conceitos de programação enquanto oferece funcionalidades relacionadas ao cadastro e gerenciamento de eventos.

## Paradigmas de Programação

### Programação Imperativa

Utiliza instruções sequenciais, estruturas de controle, variáveis e alterações de estado para definir o comportamento do sistema.

### Programação Orientada a Objetos

Organiza o sistema utilizando objetos e classes, permitindo representar elementos da aplicação por meio de atributos e métodos.

### Programação Funcional

Utiliza funções como elementos fundamentais para estruturar e processar dados, buscando uma abordagem baseada na composição e aplicação de funções.

### Programação Lógica

Baseia-se na definição de fatos, regras e relações para representar informações e permitir a obtenção de resultados a partir dessas relações.

## Tecnologias

O projeto foi desenvolvido utilizando tecnologias voltadas ao desenvolvimento de aplicações web e programação.

* Python
* Flask
* HTML
* CSS
* JavaScript

## Finalidade Acadêmica

O EventosUni foi desenvolvido com finalidade **acadêmica**, tendo como principal propósito demonstrar a aplicação prática dos diferentes paradigmas de programação em um único projeto.

A utilização de um sistema de eventos como contexto permite apresentar os conceitos de maneira mais concreta, relacionando a teoria estudada em sala de aula com uma aplicação funcional.
